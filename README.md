# Windows Server 优化助手 SrvDesk

给 **Windows Server 2019 / 2022 / 2025**（也可用于 Windows 10/11）做本机优化：能改哪些、为什么改、风险多大，确认后再写进系统。

当前版本：**1.0.33** · [Releases 下载](https://github.com/gygy/SrvDesk/releases)

[English](README_en.md)

---

## 下载与运行

1. 打开 [Releases](https://github.com/gygy/SrvDesk/releases)，下载 **`SrvDesk.exe`**（单文件，轻度混淆）。
2. 右键 → **以管理员身份运行**。
3. 第一次打开会有简短说明；正式改系统前建议先看 **工具 → 优化顾问**（主界面顶部「常用软件」旁也有入口）。
4. 免责声明、隐私说明、许可证在 **帮助** 菜单。

**系统要求：** Windows Server 2016+（更建议 2022/2025，带桌面体验）；Windows 10/11 也能用，「Server 专属」项会藏掉或标不适用。需要 **.NET Framework 4.8**。

> 这个公开仓库只有说明和许可证，**没有源码**。程序只从 Releases 下载。

## 怎么用

1. 管理员启动 `SrvDesk.exe`。
2. 打开 **优化顾问**：按当前机器状态列出「强烈推荐 / 推荐」且尚未达标的项；可勾选后直接应用到系统。
3. 需要时在顾问里改 **服务器用途**（例如 RDP、文件共享、Docker）和优化等级。
4. 侧栏改具体开关或服务；多数开关要点底部 **应用到系统** 才会写入（可先看变更计划、建还原点）。
5. 出问题可走 **工具 → 回滚优化**（服务快照或系统还原点）。

也可用预设里的「家庭服务器 / Docker 主机 / NAS」模板，先勾到界面再决定是否写入。

---

## 侧栏大致分三类

- **即时生效：** 登录启动项、DNS、自定义配置  
- **批量写入：** Server 专属、账户策略、资源管理器、桌面外观、远程与网络、隐私与体验、性能及安全、电源与后台  
- **嵌入页：** 服务优化（带依赖、风险和用途保护）

## 工具菜单里常用的

| 入口 | 做什么 |
|------|--------|
| 优化顾问 | 按本机状态筛高价值待优化项，可勾选后写入 |
| 端口暴露 | 看监听端口，标出敏感或全网卡暴露 |
| 回滚优化 | 历史记录；服务快照 / 系统还原 |
| 定时关机、垃圾清理、可选功能、安全中心等 | 日常运维小工具 |

**帮助 → 检查更新** 会读 GitHub Releases。不想开机检查，可在 **文件 → 程序设置** 关掉。  
「应用到系统前是否弹出变更计划」也在程序设置里。

## 怎么改系统

原则就一条：**缺什么补什么，不靠「关得越多越快」。**

每条建议尽量写清：为什么、好处、风险、影响范围、能不能回滚。
