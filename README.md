# Windows Server 优化助手 SrvDesk

面向 **Windows Server 2019/2022/2025**（亦适用于桌面）的本机优化助手：  
**先识别用途 → 健康检查 → 可解释建议 → 干跑确认 → 执行 → 验证/回滚 → 持续巡检**。  
不盲目关闭服务，在性能、稳定、安全、兼容之间求平衡。

当前版本：**1.0.33** · [Releases 下载](https://github.com/gygy/SrvDesk/releases)

[English](README_en.md)

## 下载与运行

1. 打开 [Releases](https://github.com/gygy/SrvDesk/releases) 下载 **`SrvDesk.exe`**（单文件，轻度混淆）。
2. **右键 → 以管理员身份运行**。
3. 首次打开会有说明；建议先打开 **工具 → 优化顾问**。
4. 完整条款见 **帮助 → 免责声明 / 隐私说明 / 许可证**。

**系统要求：** Windows Server 2016+（推荐 2022/2025，带桌面体验）；也可用在 Windows 10/11（「Server专属」项会隐藏或不适用）。需 **.NET Framework 4.8**。

> 本仓库只放说明与许可证，**不含源码**。程序只从 Releases 获取。

## 快速上手（推荐闭环）

1. 管理员启动 `SrvDesk.exe`
2. **工具 → 优化顾问**：查看 ①–⑥ 诊断流程、健康度与问题；可打开服务器用途、优化建议
3. 在顾问内设置用途（RDP / 文件共享 / Docker 等）与优化等级（仅检测 / 安全 / 标准 / 深度）
4. 侧栏开关 + 服务优化：查看可解释建议
5. 底部 **应用到系统**：先出变更计划（干跑确认），再写入；可创建还原点
6. **工具 → 回滚优化**：服务快照还原或系统还原点

亦可用预设中的「家庭服务器 / Docker 主机 / NAS」用途模板。

## 工具

| 入口 | 作用 |
|------|------|
| 优化顾问 | ①–⑥ 诊断流程、健康分、问题、洞察；内含用途/建议/巡检 |
| 端口暴露 | 监听端口，标敏感/全网卡 |
| 回滚优化 | 历史记录 + 服务快照 / rstrui |
| 定时关机 / 垃圾清理 / 可选功能 / 安全中心 等 | 既有工具箱 |

**帮助 → 检查更新** 读 GitHub Releases。启动检查可在 **文件 → 程序设置** 关闭。  
程序设置中可开关「应用到系统前显示变更计划」。

## 设计原则

> **不是「关闭越多越快」，而是「只修改确定不需要的东西」。**

每项建议尽量包含：原因、收益、风险、影响、可否回滚。
